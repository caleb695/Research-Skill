# Fixed-task research audit playbook

This skill runs only the prompt in `fixed-task.md`. Use this playbook to choose
the next research target inside that fixed task; do not create generic coding or
improvement rounds.

## Selection rule

Score each candidate: `impact × confidence ÷ effort`.

- **impact** — how much the finding would affect the strongest for/against claims.
- **confidence** — how sure you are that the gap or weakness is real, based on
  cited evidence.
- **effort** — how much work to check properly in one round-sized unit.

Pick the highest score. Break ties toward hard evidence: an unchecked primary
source, a missing locator, a contradictory date, a dependent citation chain, or
an unresolved objection.

Write the decision before searching:

```text
Round N target: <evidence gap/objection> — because <evidence>. Score 4×5/2.
```

## Every-round audit

1. Restore the ledger and reports; run the research validator.
2. Use the next alternating side from state.
3. Look for the weakest link in the current case: unauthenticated item, missing
   context/POV, missing source locator, duplicate identity, unsupported score,
   missing opposite-side comparison, or category with no coverage.
4. Prefer primary texts and original records over repeated summaries.
5. Record searches and access limits honestly; never invent a finding to make the
   round look productive.

## Escalation when novelty dries up

1. **Authenticate** — locate the earliest source and check exact wording/provenance.
2. **Contextualize** — read the whole passage/document/excavation context.
3. **Compare** — test the item against the strongest opposite-side evidence.
4. **Deduplicate** — map shared sources, datasets, informants, and assumptions.
5. **Deepen** — read scripture/primary records directly and build reproducible tables.
6. **Revisit** — after prolonged fruitless searching, re-check uncertain and
   confident claims for stronger corroboration or better objections.
7. **Synthesize** — label original comparisons/hypotheses as original synthesis,
   not newly discovered historical facts.

## Signal that a round was worth it

Answer yes to at least one:

- A claim became better supported or properly weakened.
- A fabricated, misquoted, miscontextualized, or duplicate item was caught.
- A primary source, locator, date, or dependency chain was verified.
- An opposing argument was evaluated rather than ignored.
- A reproducible original comparison or hypothesis was recorded.

If no, log the fruitless search and change route/category; do not stop or fake
progress.
